# Data Structures Using C++

**Course Title:** Data Structures Using C++  
**Course No:** P2CSTC201  

This repository contains **from-scratch C++ implementations of Data Structures and Algorithms**, organized strictly according to the academic syllabus.

The repository is **code-first**:
- Every concept is demonstrated through executable C++ programs
- Minimal theory, maximum implementation
- No reliance on STL unless explicitly stated
- Suitable for **exams, interviews, and core CS revision**

---

## 🎯 Repository Objectives

- Implement all major data structures manually
- Understand internal working, not just usage
- Analyze time and space complexity through code
- Maintain clean, readable, and testable C++ programs

---

## 📘 Unit Overview

### 📂 [UNIT–I: Fundamental Notations](UNIT-01-Fundamental-Notations/README.md)

Focuses on algorithm foundations and analysis:
- Data representation
- Self-referential structures
- Time & space complexity
- Asymptotic notation via code examples

> Purpose: Build analytical thinking before writing complex structures.

---

### 📂 [UNIT–II: Linear Data Structures](UNIT-02-Linear-Data-Structures/README.md)

Implements sequential structures without STL:
- Arrays
- Linked Lists (SLL, DLL, CLL)
- Stacks (array & linked list)
- Queues (linear, circular, deque)

> Purpose: Master pointer logic and memory management.

---

### 📂 [UNIT–III: Non-Linear Data Structures](UNIT-03-Non-Linear-Data-Structures/README.md)

Implements hierarchical and network-based structures:
- Binary Trees
- Tree traversals
- Binary Search Trees
- Heaps
- Graphs with BFS and DFS

> Purpose: Learn recursion, traversal, and relationship modeling.

---

### 📂 [UNIT–IV: Indexing Structures](UNIT-04-Indexing-Structures/README.md)

Implements fast-access data structures used in systems:
- ISAM
- m-Way Trees
- B-Trees
- B+ Trees
- Hashing with collision resolution

> Purpose: Understand how databases and file systems index data.

---

### 📂 [UNIT–V: Sorting & Searching](UNIT-05-Sorting-and-Searching/README.md)

Implements classic algorithms with comparisons:
- Bubble, Selection, Insertion
- Shell, Quick, Merge, Radix
- Linear and Binary Search

> Purpose: Compare algorithm efficiency and behavior.
